# Campher & B-Yond | Corporate website

This folder is a ready-to-upload static website for GitHub Pages, using the approved Campher & B-Yond logo.

## Important
- Use the exact registered name **Campher & B-Yond**.
- Corporate slogan: **Catalyst for Change, Champion of Growth**.
- The founder’s historical Red Cross programmes are clearly identified as his previous professional experience, not contracts delivered by Campher & B-Yond.
- The approved AI-generated branding is intended for design use; trademark and original-platform licensing clearance have not been completed.
- Do not publish a private home address or registration numbers unless you expressly want them public.

## Publish through your existing GitHub account
1. Log into GitHub using your **Fernelc** account.
2. Create a NEW public repository named `campher-b-yond` (leave the existing `fernelc.github.io` repository untouched).
3. Select **Add file → Upload files** in the new repository. Upload **all contents of this folder** (including `index.html`, `assets`, and `.nojekyll`), not the parent folder or ZIP.
4. Commit to the main branch.
5. In the new repository open **Settings → Pages**. Set Source to **Deploy from a branch**, branch **main**, directory **/(root)**. Save.
6. After GitHub Pages deploys, check `https://fernelc.github.io/campher-b-yond/`.

## Updating later
Edit files only in the new company repository. To avoid merge conflicts, do not simultaneously edit the same files online and in GitHub Desktop without pulling changes first.
